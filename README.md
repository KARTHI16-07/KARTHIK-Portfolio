# Karthik — Portfolio Website

Simple multi-page portfolio site. No build tools, no server needed — just HTML + CSS.

## Files

```
portfolio/
├── index.html      → Home page
├── about.html      → About
├── skills.html      → Skills
├── projects.html    → Projects
├── resume.html      → Resume + Education
├── contact.html     → Contact
└── style.css        → Shared styles for all pages
```

## How to run it

1. Keep all files in the **same folder** (don't separate them).
2. Double-click `index.html` — it opens in your browser.
3. Use the top nav to move between pages.

That's it. No installation, no npm, nothing.

## How to edit

Open any `.html` file in a text editor (VS Code, Notepad, etc.) and change the text directly.

Things to update before sharing:
- `contact.html` → replace email, phone, GitHub, LinkedIn placeholders
- `projects.html` → replace `#` links with your real GitHub repo links
- `resume.html` → link the "download resume.pdf" button to your actual resume file

## How to put it online (free)

1. Create a GitHub account (if you don't have one).
2. Create a new repository named `portfolio`.
3. Upload all the files above into it.
4. Go to **Settings → Pages** → set Branch to `main` → Save.
5. Your site goes live at:
   `https://yourusername.github.io/portfolio`

Use that link in your resume and LinkedIn.
